# Tableau Sales Analysis & Visualization

## 📌 Project Overview

This project focuses on analyzing sales data and creating interactive visualizations and dashboards using **Tableau**. The analysis provides insights into sales performance, country-wise sales, and salesperson performance.

## 📊 Dashboards & Visualizations

* **Sales by Country** – Visualizes and compares sales performance across different countries.
* **Top 10 Salespersons** – Identifies the top-performing salespersons based on sales.
* **Business Summary Dashboard** – Presents key business insights and performance metrics in an interactive dashboard.
* **Advanced Visualizations** – Uses filters, calculated fields, charts, and interactive dashboard features.

## 🛠️ Tools & Skills

* Tableau
* Data Visualization
* Data Analysis
* Dashboard Creation
* Filters & Calculated Fields
* Sales Performance Analysis
